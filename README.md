# Пчела (MDS)

Децентрализованный поиск. Каждая нода — пчела. Связанные ноды — рой. Региональная точка входа — улей.

Исходники здесь, чтобы собрать ноду и дорабатывать её вместе. Готовые файлы, которые скачивают и запускают:

- [Windows, 64-бит](https://github.com/artemklimovich/mds/releases/latest/download/pchela-windows-x64.zip)
- [Linux x86_64, Ubuntu 24.04 и другие Linux с glibc 2.39](https://github.com/artemklimovich/mds/releases/latest/download/pchela-linux-x64.tar.gz)

Одна программа. Мини-нода, полная нода и нода на свободный компьютер запускаются разными командами, это написано в `README.txt` внутри архива. Приложения для Android нет.

Как устроен поиск, рой и лёгкая пчела: [docs/architecture.md](docs/architecture.md). Что получает участник за свою машину: [docs/rewards.md](docs/rewards.md).

## Что не лежит в репозитории

Папка `data/` в git не входит.

- `data/models/swarm` — веса `multilingual-e5-small`. Полная нода забирает их с улья. Лёгкая пчела модель не качает.
- `data/onnx/onnxruntime.dll` версии 1.20 — нужна только полной ноде (поиск и эмбеддинги). Лёгкая пчела обходится без неё.
- `data/mds.db` — свой индекс ноды.
- `data/release.key` — закрытый ключ издателя. Его не передают.

## Сборка

Нужны Rust stable и компилятор C (на Windows — MinGW).

```
cargo build --release -p mds-cli
```

Готовый файл: `target/release/mds.exe` (на Linux и macOS — `target/release/mds`).

## Полная нода

Поиск, обход и эмбеддинги. Нужны `onnxruntime.dll` и место под модель (около 1 ГБ памяти).

```
mds node --seeds urls.txt --follow-external --listen 127.0.0.1:8080
```

Страница поиска: `http://127.0.0.1:8080/`.

## Лёгкая пчела на сервере сайта

Без модели и без своей выдачи. Раз в 10 минут забирает свои страницы и до четырёх чужих адресов, которые дал улей, и отдаёт текст улью.

```
mds node --lite --site https://адрес-сайта --hive https://45.158.46.52
```

Имя, которое пчела печатает при запуске, кладётся одной строкой в `https://адрес-сайта/.well-known/pchela.txt`. Общий пароль для входа не нужен. Новую сборку на этот сервер кладут вручную и перезапускают службу: лёгкая пчела свой файл не меняет.
