# MDS

**Нода в децентрализованной поисковой сети.** Агент подключается по MCP и ищет без оплаты за запрос. Чем больше нод и краёв в одной сети — тем больше индекс. Кто ставит ноду и входит в рой, работает на сеть и получает поиск по общему индексу, а не только по тому, что обошла его машина.

Agent infrastructure: connect a node, join the swarm, search the combined index over MCP. No per-query bill. Data does not leave your door for a foreign search API.

Это не замена Google. Это слой, на котором агент живёт, и сеть, в которой индекс складывается из участников.

Публичное имя сети — [Пчелопоиск](https://beesearch.ru). Программа — `mds`.

## Зачем

Агент делает тысячи поисковых запросов в день. У внешнего поиска это счёт и потолок.

- Google Custom Search JSON API: **5 $ за 1000 запросов**, потолок **10 000 в сутки**, для новых клиентов закрыт. Десять тысяч запросов в день — это уже потолок API и порядка 50 $ в сутки.
- Тот же объём через ноду: **0 за запрос**. Платите машину и диск, не чужой счётчик.
- Один сервер не удержит весь интернет. Ноды и края **объединяются**: каждая держит кусок, поиск идёт по сети. Чем больше участников — тем больше корпус, без центральной компании-базы.
- Кто вошёл в одну сеть, получает **тот же поиск, что и сеть**, не карманный индекс своей машины. За это его нода обходит страницы, хранит шард и отвечает соседям.

Корпоративная нода может остаться в периметре и не входить в публичный рой: тогда агент видит только ваш архив и интранет. Это выбор, не обязанность.

## Как

```text
агент --MCP--> ваша нода ----+
                             |     шарды края
другие ноды того же края ----+--> улей края <--> ульи других краёв
                             |
обход HTTP(S): сайты, интранет, архивы, файловый сервер
```

- **Нода** держит свой кусок индекса и считает смысл запроса моделью на процессоре (`multilingual-e5-small`, ONNX). Видеокарта не нужна.
- **MCP** — дверь владельца к своей ноде: поиск, выгрузка, гео, метки, состояние. Несколько ключей — несколько агентов. Ключ выдаётся в кабинете, показывается один раз, отзывается отдельно от пароля.
- **Рой** — ноды одного края, связанные картой. С четвёртой машины индекс делится на шарды, а не копируется целиком на каждый диск. Запрос спрашивает держателей нужного куска.
- **Улей** — вход края для людей и агентов. Другой край не копируется сюда: поиск в том крае идёт на его улей. Сеть растёт числом машин и числом краёв.

Нода без соседей отвечает только своим диском. Нода в рое отдаёт свой кусок и читает чужие через улей и соседей — в этом и есть общий индекс.

Устройство шардов и обхода: [docs/architecture.md](docs/architecture.md). Что получает владелец машины: [docs/rewards.md](docs/rewards.md).

## Одна сеть

Поставить ноду и подключить её к рою — это не «свой маленький Google», а участие.

1. Вы **работаете на поисковую сеть**: обход, хранение шарда, ответ на запрос соседа.
2. Вы **получаете функцию всей сети**: агент и человек ищут по индексу роя и, через улей другого края, по индексу других регионов — не по одному локальному файлу.
3. Чем больше нод и краёв, тем шире выдача. Нет одного склада, который кто-то выключил — и поиск кончился.

Лёгкая пчела на сервере сайта в ту же сделку входит иначе: модели нет, своего индекса нет, зато свои страницы уходят в общий индекс, потолок в сто страниц снимается, и сайт начинает находиться в сети.

Открытой выгрузки всей базы чужому человеку нет: ищут через строку поиска или через свой ключ MCP. Журнал запросов остаётся на ответившей ноде.

## Два варианта

Одна программа, два контура. Их не смешивают без решения владельца.

1. **Общая сеть.** Ставите ноду и подключаете к рою. Машина работает на децентрализованный поиск: обход, шард, ответ соседям. Агент и человек получают поиск по индексу сети и других краёв, не по одному локальному диску. Лёгкая пчела на сайте — тот же контур: своих страниц больше в индексе, своего поиска на машине нет.
2. **Свой периметр.** Нода только для внутренних систем: сайты корпоративной сети, архивы документов, открытые папки и файловый сервер (сейчас — то, что отдаётся по HTTP(S) или WebDAV). Агенты компании ищут по MCP, люди — на странице этой ноды. В публичный рой этот корпус не уходит.

| Контур | Сеть | Что в индексе | Кто ищет |
| --- | --- | --- | --- |
| Нода в рое | Вариант 1 | Публичные сайты, которые обошли вы и соседи; другие края — через их улей | Агент по MCP этой ноды, люди на улье |
| Улей края | Вариант 1, вход региона | Индекс края плюс запрос в соседний край | Люди на [beesearch.ru](https://beesearch.ru) и на своём домене, агенты с ключом |
| Нода в офисе | Вариант 2, без роя | Интранет, архив, каталоги файлового сервера | Агенты компании, люди на странице этой ноды |
| Лёгкая пчела на сайте | Вариант 1 | Свои страницы уходят в индекс сети | Ищут на улье, не на этой машине |

Обход сейчас — **HTTP и HTTPS**. Открытая папка в локальной сети или шара файлового сервера попадает в индекс, если её отдаёт веб-сервер (IIS, nginx, Nextcloud, WebDAV). Отдельного клиента SMB в этой версии нет: нода не ходит в `\\server\share` сама.

В индекс уже входят страницы и файлы с веба: PDF, DOC, DOCX, XLS, XLSX, RTF. Тот же разбор работает для архива на внутреннем портале.

## Попробовать

Люди: строка поиска на [beesearch.ru](https://beesearch.ru).

Агент: ключ на листе «Дверь» кабинета ноды. Адрес MCP улья: `https://admin.beesearch.ru/mcp`. На своей ноде — `{база-кабинета}/mcp`.

Cursor (`~/.cursor/mcp.json` или настройки проекта):

```json
{
  "mcpServers": {
    "beesearch": {
      "url": "https://admin.beesearch.ru/mcp",
      "headers": {
        "Authorization": "Bearer ВСТАВЬТЕ_КЛЮЧ"
      }
    }
  }
}
```

Проверка без IDE:

```bash
curl -sS https://admin.beesearch.ru/mcp \
  -H "Authorization: Bearer ВСТАВЬТЕ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"tools/call\",\"params\":{\"name\":\"search\",\"arguments\":{\"q\":\"онлайн-касса\"}}}"
```

Инструменты, с которых агент обычно начинает: `search`, `geo_places`, `index_pages`, `kind_counts`, `node_status`. Полный список отдаёт `tools/list`. Параметр `kind` сужает корпус (`docs`, `news`, `gov`, `shop` и остальные метки ноды).

## Сборки Пчелопоиска

Каждая полная нода в сети — пчела. Связанные ноды — рой. Вход края — улей. Как они складывают индекс, написано выше.

Готовые сборки:

- [Windows, 64-бит](https://github.com/artemklimovich/mds/releases/latest/download/pchela-windows-x64.zip)
- [Linux x86_64, glibc 2.39+](https://github.com/artemklimovich/mds/releases/latest/download/pchela-linux-x64.tar.gz)

Одна программа. Мини-нода, полная нода и нода на свободный компьютер — разные команды, они в `README.txt` внутри архива. Приложения для Android нет.

## Сборка

Нужны Rust stable и компилятор C (на Windows — MinGW).

```
cargo build --release -p mds-cli
```

Готовый файл: `target/release/mds.exe` (на Linux и macOS — `target/release/mds`).

## Полная нода

Поиск, обход, эмбеддинги, MCP. Нужны ONNX Runtime 1.20 и место под модель (около 1 ГБ памяти).

```
mds node --seeds urls.txt --follow-external --listen 127.0.0.1:8080
```

Страница поиска: `http://127.0.0.1:8080/`. Кабинет и MCP — отдельный порт, см. [docs/deploy-nginx.md](docs/deploy-nginx.md).

## Лёгкая пчела на сервере сайта

Без модели и без своей выдачи. Раз в 10 минут забирает свои страницы и до четырёх чужих адресов, которые дал улей, и отдаёт текст улью.

```
mds node --lite --site https://адрес-сайта --hive https://45.158.46.52
```

Имя, которое пчела печатает при запуске, кладётся одной строкой в `https://адрес-сайта/.well-known/pchela.txt`. Общий пароль для входа не нужен.

```
mds update --hive https://beesearch.ru
```

Команда забирает с улья файл своей системы, сверяет подпись и ставит его на место. Карточка `pchela.txt` не меняется. Рядом с архивом на странице загрузки лежит контрольная сумма SHA256.

## Что не лежит в репозитории

Папка `data/` в git не входит.

- `data/models/swarm` — веса `multilingual-e5-small`. Полная нода забирает их с улья. Лёгкая пчела модель не качает.
- `data/onnx/onnxruntime.dll` версии 1.20 — нужна только полной ноде.
- `data/mds.db` — свой индекс ноды.
- `data/release.key` — закрытый ключ издателя. Его не передают.
