# Вознаграждение участников

Пчелопоиск не платит за ноду деньгами. Выдачу не продают, рекламодателя в ней нет. Вознаграждение — то, что человек получает за свою машину.

Подробности устройства сети: [architecture.md](architecture.md).

## Лёгкая пчела

Стоит на сервере сайта. Модель не качает, чужой поиск не открывает, чужой трафик через сайт не гоняет.

Сайт получает:

- потолок в сто страниц снимается: улей принимает страницы, которые пчела сама отдаёт;
- свежие страницы уходят на улей раз в десять минут;
- в выдаче значок «держит пчелу»;
- среди близких результатов ссылка поднимается на 5 процентов. Страница с более точным совпадением слов остаётся выше.

За это пчела обходит до четырёх чужих адресов, которые выдал улей. Адреса выбирает улей. Своего индекса у лёгкой пчелы нет, поэтому читать чужой индекс ей нечего.

## Полная нода

Полная нода держит индекс, считает смысл запроса и открывает свой поиск. Журнал запросов остаётся на этой машине.

Владелец уже получает свой адрес поиска для края или компании и ответ, который живёт, даже если другой улей встал.

Дополнительное вознаграждение за диск и модель — чтение индекса, который держит эта нода. Владелец подключается к ней по API и по MCP и забирает результат для своей работы: страница сайта, таблица, подбор вакансий, список организаций, услуг, документов. В ответе то, что уже лежит в поиске: адрес страницы, заголовок, текст, тип страницы и край.

Это дверь на свою ноду. Ею пользуется тот, кто её поставил. Открытого склада всего улья для любого человека из интернета нет: чужой человек ищет на странице поиска, а не выгружает базу. Журнал запросов людей в эту выдачу не входит. Лёгкая пчела и телефон эту дверь не получают: индекса, которым можно пользоваться как своей базой, у них нет.

Дверь открыта на адресе `https://admin.<домен-ноды>/mcp`. Это MCP: владелец сначала входит в кабинет и один раз видит ключ. Ключ читает индекс этой ноды, её статистику и подписанную карту. Чужой журнал и файл чужой базы он не отдаёт. Для другого края поиск возвращает адрес улья этого края.

## Свободный компьютер

Без белого адреса он не принимает чужих людей из интернета. На нём можно искать локально и отдавать улью обойдённые страницы. Если это полная нода, чтение индекса то же, что у полной ноды. Если это лёгкая пчела, вознаграждение то же, что у лёгкой пчелы.

## Телефон

Телефон хранит маленький кусок для владельца. Это запасная копия, а не вход для чужих и не прокси. Чужой трафик через телефон не идёт.
